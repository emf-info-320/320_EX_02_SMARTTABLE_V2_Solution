# Tableau intelligent 2
[Accueil](../../README.md)
## Durée : 30'

## Objectifs visés

Réactivation des fondamentaux Java : en particulier boucles et tableaux.

Réactivation des fondamentaux Java : classes, instances et static.

Découverte des fondamentaux de la classe ArrayList.

## Travail à réaliser
1. Votre travail consiste à nouveau à implémenter les méthodes actuellement vides de la classe SmartStringTable.
2. Le cahier des charges de ces méthodes est inchangé.
3. Il vous faut cette fois-ci les implémenter en utilisant les fonctionnalités de la classe ArrayList.

Prenez le temps de bien chercher dans les fonctionnalités de cette classe ArrayList, vous verrez qu’elle vous fournit quasiment directement tout ce que vous pourriez souhaiter.
